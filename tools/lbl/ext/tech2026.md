# tech2026: copper, redstone, rails, ocean and workstation blocks

Module: `tools/lbl/ext/tech2026.py` (textures in `_tex_tech2026.py`, all original procedural art).
Names are the Bedrock display names (checked on minecraft.wiki, October 2026). "Light" is the block light
level from the wiki. "New" is the Bedrock version that added the block (only for 2024 to 2026 additions):
`1.21.0` = Tricky Trials (June 2024), `1.21.111` = The Copper Age (September 2025).

**Powered and unpowered states are separate keys.** To flip a gadget between frames, swap the key
(`repeater` -> `repeater_on`, `copper_bulb` -> `copper_bulb_lit`). Both keys show the same item name.

**Redstone dust joins the new parts on its own.** Dust already joined dust, torches, lamps, pistons and so on.
The end of `tech2026.py` wraps `dust_mask` (in both `engine` and `plans`) so dust also joins the unlit torch,
copper bulbs (every stage, lit or not, waxed or not), target, crafter, dispenser, dropper and detector rails from
any side; repeaters and comparators only in front of or behind them (along `f`); observers only at their back
(the side opposite `f`, where they send power out). `rs=True` on any cell still forces a join.
Integration TODO: move the `dust_link` check into `engine.dust_mask` and delete the wrapper.

## Rails

| key | name | light |
|---|---|---|
| `rail` | Rail | |
| `powered_rail` / `powered_rail_on` | Powered Rail (gold rails, red line glows when on) | |
| `detector_rail` / `detector_rail_on` | Detector Rail | |
| `activator_rail` / `activator_rail_on` | Activator Rail | |

All use the `rail` shape, a flat track:
- `a='z'` (default) runs north-south, `a='x'` runs east-west.
- `f='E'` alone: a ramp going **up** toward east. Put a block under the next cell and a rail on top of it.
- `f` and `side` together (plain `rail` only): a curve joining those two sides, e.g. `f='S', side='E'`.

## New shapes (EXTRA_SHAPES)

| shape | state | item |
|---|---|---|
| `chain` | `a='y'` (hanging, default), `'x'`, `'z'` | block name |
| `repeater` | `f`, `delay` 1..4 | Redstone Repeater |
| `comparator` | `f` | Comparator |
| `facing` | `f` = N/E/S/W/U/D; works with any block that has a front (furnace, dispenser, observer back light) | block name |
| `piston_base`, `piston_head` | `f` = N/E/S/W/U/D | base: Piston / Sticky Piston; head: not counted |
| `rail` | `a`, or `f` (ramp up toward f), or `f` + `side` (curve) | block name |
| `cross_plant` | none (height comes from the block) | block name |
| `coral_fan` | `side` (on a wall) or none (floor) | block name |
| `sea_pickle` | none (count comes from the key) | Sea Pickle |
| `conduit` | none | Conduit |
| `lectern` | `f`, `book` | Lectern |
| `grindstone`, `stonecutter` | `f` | block name |
| `decorated_pot` | none | Decorated Pot |
| `candle` | `n` 1..4 | block name (one item per spot, even with `n` > 1) |
